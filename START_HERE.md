# Start here

CourtIQ is the working implementation of your 30-day plan. The project files
are available in your Tennis-Project GitHub repository and in the prepared cloud workspace.

## 1. Understand what you have

Open README.md for setup, reports/case_study.md for findings, and RESUME.md for
accurate project bullets and interview preparation. Keep 30_DAY_PLAN.md as your
learning checklist; having working code does not replace understanding it.

## 2. Run in this prepared cloud workspace

In a terminal:

```bash
cd /workspace/Tennis-Project
/workspace/courtiq-venv/bin/python -m streamlit run app.py
```

The dependencies and historical database are already prepared. On another
computer, follow README.md instead. If you download the source archive, extract
it and use Python 3.12. It intentionally omits the source dataset; the downloader
retrieves the pinned files during setup.

## 3. Make it your own

Compare two players using the same years and surface. Read the denominators.
Trace one record into SQL. Add an analysis question and a test you understand.
Keep your own learning notes. Be transparent about AI assistance in interviews.

## 4. Download from GitHub and, later, use it on your resume

Open https://github.com/daniellee07/Tennis-Project, click the green **Code**
button, and choose **Download ZIP**. Extract the ZIP on your computer. Follow the
README setup from inside the extracted folder. Downloading gives you the source
code; it does not install Python or launch the dashboard automatically.

For public hosting, follow DEPLOYMENT.md and resolve the source-data distribution
permissions first. Test a real public link before adding it to your resume.
Use RESUME.md only after reproducing the project and practicing its explanation.
